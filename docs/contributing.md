# Contributing to Cortex Linux

We welcome contributions to both the operating system and this documentation!

## 1. Contributing Code

1.  Fork the main `cortexlinux/cortex` repository.
2.  Create a feature branch (e.g., `feature/fix-llm-bug`).
3.  Submit a Pull Request targeting the `main` branch.

## 2. Contributing Documentation

1.  Fork the repository and create a feature branch (`docs/update-installation`).
2.  Edit the Markdown files in the `docs/` folder.
3.  Submit a Pull Request. Changes are automatically deployed via GitHub Pages after merge!
