# Usage Guide

Cortex Linux focuses on command-line integration with large language models (LLMs).

## Key Features

1.  **AI Command Interpretation:** Use natural language queries in the terminal (e.g., "Find all Python files modified yesterday").
2.  **AI Shell Assistance:** The shell provides contextual help and debugging suggestions using the integrated LLM.

## Basic Commands

| Command | Description |
| :--- | :--- |
| `cortex-assist` | Opens a direct chat interface with the system LLM. |
| `ai-find` | Intelligent file search powered by a semantic search model. |
