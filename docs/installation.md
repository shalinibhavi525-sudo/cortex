# Installation Guide

Follow these steps to get the AI-Native OS running.

## 1. Prerequisites

Ensure you have:
* A USB drive (minimum 8GB).
* A stable internet connection.

## 2. Download the ISO

The latest stable ISO image can be downloaded from our [releases page].

## 3. Creating Bootable Media

We recommend using **Balena Etcher** or **Rufus** to create a bootable drive. Select the downloaded `.iso` file, choose your USB drive, and click "Flash."
